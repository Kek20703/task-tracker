# Этап 10. Frontend

> Статус постановки: `утверждена`. Дата утверждения: 2026-11-13. Ветка: `feature/frontend`.
> После утверждения изменения — только отдельным решением.

## Цель

Локальный SPA для ручной проверки API: регистрация, вход, список задач, создание, редактирование,
смена статуса и удаление. Отдельный проект, backend не меняется.

## Границы

Входит:

- `task-tracker-frontend` на React + Vite + TypeScript;
- страница входа/регистрации;
- список задач с фильтрами «все / активные / выполненные»;
- создание, редактирование, `TODO ↔ DONE`, удаление;
- dev-прокси `/api` → `http://localhost:8080`, без CORS;
- адаптивная вёрстка и обработка ошибок API.

Не входит:

- деплой фронтенда и SSR;
- восстановление пароля, профиль, смена email;
- e2e-тесты в браузере;
- интеграция с summarization/scheduler.

## Контракты API

- `POST /user`, `POST /auth/login` → пользователь в теле, токен в `Authorization`.
- `GET /user` — текущий пользователь.
- `GET /tasks`, `POST /tasks`, `PATCH /tasks/{id}`, `DELETE /tasks/{id}`.
- Ошибки — JSON `{"message": "..."}`.
- Токен хранится в `localStorage`, передаётся как `Authorization: Bearer ...`.

## Запуск

```bash
cd task-tracker-frontend
npm install
npm run dev
```

Открыть http://localhost:5173; backend — http://localhost:8080.
